# specify-feature

Write a feature spec under `docs/specs/` using `docs/templates/feature-spec.md`.

1. Read `docs/PRODUCT.md`, `docs/SECURITY.md`, and `GLOSSARY.md`.
2. Draft testable acceptance criteria and proposed seams (see `docs/TRADUZ-TDD.md`).
3. Save to `docs/specs/<feature>.md`.
4. Stop unless the user asked to implement.
